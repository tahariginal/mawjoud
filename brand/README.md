# Mazal — brand assets

Open `index.html` in a browser for the full sheet.

**Concept:** a tagine whose knob is a fresh leaf — Moroccan food that is still good ("mazal" means "still"). Majorelle blue, from the Jardin Majorelle in Marrakech, is the brand color and the color of every primary action in the app; green stays for freshness and savings.

| File                            | Use                                                               |
| ------------------------------- | ----------------------------------------------------------------- |
| `logo/mazal-logo.svg`           | Primary logo (symbol + wordmark), light backgrounds               |
| `logo/mazal-logo-white.svg`     | Logo on Majorelle or dark backgrounds                             |
| `logo/mazal-symbol.svg`         | Symbol alone                                                      |
| `logo/mazal-symbol-white.svg`   | Symbol on dark backgrounds                                        |
| `logo/mazal-wordmark.svg`       | Wordmark alone                                                    |
| `logo/mazal-wordmark-white.svg` | Wordmark on dark backgrounds                                      |
| `logo/mazal-app-icon.svg`       | App icon source                                                   |
| `png/*.png`                     | Transparent PNG exports (1600 px logos, 1024 px symbols and icon) |

The app's icons in `apps/mobile/assets/images/` are generated from the same symbol.

## Colors

| Name              | Hex       | Use                                                                |
| ----------------- | --------- | ------------------------------------------------------------------ |
| Majorelle         | `#6050DC` | Brand, primary buttons, selected states, links (white text 5.71:1) |
| Majorelle pressed | `#4A3BC2` | Pressed primary (white text 7.79:1)                                |
| Ink               | `#111111` | Text and icons                                                     |
| Green             | `#0B7A4B` | Leaf on white, savings, "Open now", success                        |
| Mint              | `#9FE3BF` | Leaf on Majorelle only                                             |

## Rules

- Clear space: at least the height of the leaf on every side. Minimum size: logo 96 px wide, symbol 24 px.
- Leaf green on light backgrounds, mint on Majorelle — never blue, never green on blue.
- Do not stretch, rotate, outline, add shadows or change the blue.
- The wordmark is drawn, not typed: always use the files, not a font.

## Name

The wordmark reads **mazal**, as chosen on 2026-10-03. On that date "Mazal App" (a London restaurant, Food & Drink) existed on the App Store and an app named "Mazal" on Google Play; `mazal.ma` and `mazal.com` were taken, `mazalapp.ma`/`.com` and `mazalfood.ma`/`.com` were free. Use a longer store title (e.g. "Mazal – Food rescue") and run an OMPIC trademark search before launch. The app is named Mazal everywhere in the code since 2026-10-03.
