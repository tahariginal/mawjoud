# MAWJOOd

Mobile-first marketplace for rescuing surplus food from local businesses.

**Status:** Phase 1 — architecture and product documentation, awaiting approval. No application code yet.

Start here: [docs/README.md](docs/README.md)

Planned stack (see [docs/SYSTEM_ARCHITECTURE.md](docs/SYSTEM_ARCHITECTURE.md)): Expo + React Native + TypeScript (mobile), NestJS modular monolith (API + worker), PostgreSQL + PostGIS, Redis + BullMQ, pnpm + Turborepo monorepo.

Setup, environment variables, migrations, testing and deployment instructions will be added here in Phase 2, together with `.env.example`.
